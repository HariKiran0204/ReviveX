# ML artifacts

Synthetic datasets are generated by `recoverai_eval` (see
`docs/architecture/recovery-model.md`). Fitted model directories under
`data/ml/models/` are gitignored so trained binaries are not committed.

Train locally:

```bash
uv run python -m recoverai_eval.train --seed 42 --n-cases 10000
uv run python -m recoverai_eval.evaluate --model-version recovery-v1
```

On Windows, set `PYTHONPATH` to include `packages/eval;packages/domain;packages/db;packages/providers`
if `uv run python -m recoverai_eval...` cannot find the package.
